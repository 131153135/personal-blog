虚拟机与 Linux 实验环境

虚拟化实践记录：VMware / 虚拟机软件安装 Linux 系统与网络配置。

虚拟化概念

虚拟机与物理机、容器的区别

虚拟机通过 Hypervisor 在一台物理机上模拟出完整硬件，每个虚拟机有独立操作系统；容器共享宿主机内核，更轻量。这是云计算课程中理解 IaaS 与虚拟化的基础。

环境搭建

VMware Workstation 安装 Linux 虚拟机

记录新建虚拟机、分配 CPU / 内存 / 磁盘、挂载系统镜像、分区安装，以及安装 VMware Tools 实现共享文件夹与自适应屏幕。

网络模式

NAT、桥接与仅主机网络模式对比

NAT 模式通过宿主机代理访问外网；桥接模式虚拟机与宿主机处于同一局域网；仅主机模式只能和宿主机通信。记录三种模式下 IP 地址获取方式的区别。

ip addr          # 查看虚拟机 IP
ping www.baidu.com   # 测试外网连通
ping 宿主机IP        # 测试与宿主机通信
