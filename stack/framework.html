开发框架学习记录

课程学习中接触到的前后端框架记录，按学习时间与方向整理。

后端框架

Express（Node.js Web 框架）

在 Node.js 基础上学习 Express，掌握路由定义、中间件、静态资源托管，快速搭建一个 Web 接口服务。

const express = require('express');
const app = express();
app.get('/', (req, res) => res.send('Hello Express'));
app.listen(3000);
前端基础框架

Vue 基础与组件思想

接触 Vue 的响应式数据、模板语法和组件化开发思路，理解前端框架如何通过数据驱动页面更新，区别于原生 DOM 操作。

快速入门

Spring Boot（了解阶段）

作为云计算方向学生，先了解 Java 后端框架的工程结构：自动配置、起步依赖、统一接口返回，为后续阅读项目源码打基础。

框架理解

为什么要用框架而不是纯原生开发

框架提供了约定好的目录结构、路由、配置和复用组件，减少重复造轮子；学习框架时重点理解"框架解决了什么问题"，而不只是会照着写代码。
