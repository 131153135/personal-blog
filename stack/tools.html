栏目 ② 技术栈 · 开发工具（2024 年）

开发工具清单与笔记

日常编码、版本管理、终端与调试工具清单及使用笔记。

编辑器 / IDE

VS Code 与 PyCharm

前端与脚本使用 VS Code，配合插件获得代码高亮、自动补全和格式化；Python 课程练习使用 PyCharm 进行调试与项目管理。

版本控制

Git 与 GitHub 仓库管理

掌握初始化仓库、提交、查看状态、推送远程仓库等基础操作，理解提交记录与版本回溯，课程作业和项目统一用 Git 管理。

git init
git add .
git commit -m "完成博客首页"
git push origin main
终端工具

Windows 终端 / PowerShell / SSH 客户端

使用命令行完成文件操作、安装依赖和连接远程服务器；记录常用终端命令与远程登录云端服务器的工具选择。

容器与编排工具

Docker Desktop 与 kubectl

本地使用 Docker Desktop 管理镜像和容器；配合 minikube / kubectl 进行 K8s 本地实验，这是云计算方向最常用的工程工具。

docker ps
kubectl get pods
数据库工具

MySQL 与可视化客户端

使用命令行和图形化客户端连接 MySQL，完成建库、建表、查询练习，理解数据存储与课程中后端项目的配套关系。

其他辅助工具

浏览器开发者工具、抓包与笔记软件

使用浏览器 F12 调试 HTML、CSS 和网络请求；配合 Markdown 笔记软件整理课程知识点与命令速查表。
