Node.js 后端运行环境

后端 JavaScript 运行环境学习记录：环境安装、模块化与 Web 服务。

基础入门

Node.js 环境安装与版本管理

通过官网安装包或 nvm 安装 Node.js，掌握 node -v、npm -v 查看版本，理解 npm 是 Node 自带的包管理工具。

node -v
npm -v
npm install express --save
模块化

CommonJS 模块与 require 导入导出

练习使用 module.exports 导出函数或对象，使用 require() 在其他文件中引入，理解 Node 中一个文件就是一个模块。

// 导出模块
module.exports = { greet: () => 'Hello Node' };
Web 服务

原生 http 模块启动第一个 Web 服务

不借助框架，使用 Node 内置 http 模块监听端口、响应请求，理解服务器如何接收 HTTP 请求并返回内容。

const http = require('http');
http.createServer((req, res) => {
  res.end('Hello Node.js');
}).listen(3000);
学习中

npm 项目与 package.json

理解 package.json 中项目名称、依赖、脚本命令的作用，使用 npm init 初始化项目，认识 node_modules 的含义。
