PC 开发环境搭建

日常开发所用电脑的硬件配置、操作系统与环境搭建记录。

操作系统

Windows 主机 + Linux 虚拟机双环境

日常开发使用 Windows 桌面环境，服务器、容器实验在 Linux 虚拟机中完成；通过终端、SSH 与共享文件夹在两套系统之间切换。

硬件配置

开发机配置记录（内存 / CPU / 磁盘）

记录本机 CPU 核心数、内存容量与磁盘空间。运行虚拟机和 Docker 时内存建议不低于 8GB，多开容器与 K8s 节点时需要预留足够内存。

systeminfo          # Windows 查看系统信息
wmic memorychip get  # 查看内存条信息
环境变量

Java / Node / Docker 环境变量配置

记录在 Windows 中配置 Path 环境变量，使命令行可以全局识别 java、node、docker 等命令，以及配置失败后的排查方法。

目录规范

代码目录与项目存放习惯

统一把课程项目、实验代码放在固定工作目录下，按课程 / 项目名分类，便于 Git 管理和备份，避免桌面文件杂乱。
